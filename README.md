# Counting Sort — multijugador

Basado en el juego original.

Puntaje competitivo por nivel:
- Se conservan los puntos que obtiene el jugador dentro del juego.
- + hasta 120 puntos por rapidez (2 puntos menos por cada segundo).
- -20 puntos por cada equivocación.
- El puntaje se acumula entre niveles.
- El ranking del profesor usa ese puntaje acumulado.

Ejecutar:
1. npm install
2. npm start
3. Profesor: http://localhost:3000/host.html
4. Estudiantes: http://localhost:3000/
